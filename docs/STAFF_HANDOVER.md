# 담당자 인수인계 · 주사위/보상 가안

2026-11-07 로컬 구현 기준. 이 문서는 구매자 화면에 제공하지 않습니다.

## 관리자 메뉴와 물품 지급

**주문 → 이벤트 → 수기판매 → 재고관리 → 인수인계** 순서입니다. 이벤트는 물품 지급 목록이 기본이며 인스타 인증은 내부 탭으로 이동했습니다.

1. 빵·오트밀 당첨 시 1개를 확보하고 ‘지급 대기’에 표시합니다.
2. 우유 보상은 구매자가 **우유·두유** 중 재고 있는 품목을 선택한 뒤 1개를 확보합니다. 선택 전에는 재고를 잡지 않습니다. 둘 다 품절이면 받지 않기를 선택하거나 나중에 확인합니다.
3. 담당자는 요청과 물품을 확인하고 **전달 완료 · 승인**을 누릅니다. 이미 확보했으므로 추가 차감하지 않습니다.
4. 취소하면 확보한 재고만 1개 반환합니다. 승인·취소는 다시 눌러도 한 번만 반영하며, 처리 완료 후 반대 상태로 바꿀 수 없습니다. **취소해도 다시 뽑거나 점수·주사위를 돌려주지는 않습니다.**
5. 선글라스 등 디지털 보상은 승인 대기 없이 자동 지급합니다. 기존에 지급한 기록을 새 대기로 다시 올리지 않습니다.

## 주사위 지급

| 구분 | 지급 기준 | 구매자에게 보이는 이름 | 6면 구성 (각 면 1/6) |
| --- | --- | --- | --- |
| 예판 일반 | 예약 총액 5,000원 이하 | 준비된 마법사의 주사위 · 일반 | 1, 2, 3, 4, 5, 6 |
| 예판 무지개 | 5,000원 초과~10,000원 이하 | 준비된 마법사의 주사위 · 무지개 | 2, 2, 3, 5, 6, 12 |
| 예판 은색 | 10,000원 초과~20,000원 이하 | 준비된 마법사의 주사위 · 은색 | 3, 5, 7, 9, 11, 18 |
| 예판 금색 | 20,000원 초과 | 준비된 마법사의 주사위 · 금색 | 우유, 6, 9, 11, 15, 22 |
| 현판·수기 현장 판매 | 승인된 빵 1개당 1개 | 현장 구매 주사위 | 1, 2, 3, 3, 4, 5 |
| 인스타 인증 | 계정당 1회, 전용 주사위 1개 | 인싸 마법사의 주사위 | 1, 1, 2, 2, 3, 우유 |

- 예판은 **예약 1건당 해당 등급 1개**. 예약 당시 가격·수량의 합계로 등급을 정하며 우유·두유를 포함한 총액을 사용합니다. 음료만 있는 예약은 구매 주사위를 주지 않습니다.
- 현판 우유·두유는 구매 주사위 제외. 도넛 5개 세트는 빵 1단위입니다.
- 주사위 종류·색·보유 개수만 구매자에게 표시합니다. 면 구성·확률·금액 경계는 공개 화면/API 메타데이터에 넣지 않습니다.
- 결과는 서버에서 추첨합니다. 우유 면은 **0점 + 우유·두유 선택권 1개**, 다른 면은 해당 점수를 더합니다.
- 우유 면은 결과와 선택권을 확정하고 주사위를 1개 사용합니다. 실제 음료 재고는 구매자가 선택할 때 확보합니다. 품절이나 지급 취소로 주사위를 다시 굴리지는 않습니다.
- 인스타 인증 시 우유를 직접 지급하는 기능과 선택 체크박스는 제거했습니다. 예전 인증 이력은 보존합니다.

## 점수 보상

0~30점 누적 막대의 말풍선을 눌러 점수별 보상을 확인합니다. 미달성 말풍선은 회색, 달성하면 컬러로 바뀌고 상품 받기 버튼이 나타납니다. 달성한 보상은 순서와 무관하게 **각 1회** 받을 수 있습니다. 이미 신청한 보상에는 다시 받기 버튼을 표시하지 않습니다. 30점 이후 점수·순위는 계속 누적하지만 추가 점수 보상은 없습니다.

| 점수 | 현재 구현 | 추후 구현 (화면에 예고만 표시) |
| --- | --- | --- |
| 5 | 오트밀 미니바이트 1개 | 프로필 배지 1 |
| 10 | 우유 또는 두유 1개 | 프로필 배지 2 |
| 15 | 멋진 선글라스 착용 해제 | 칭호 「멋쟁이 마법사」 |
| 20 | 랜덤 빵 1개 | — |
| 30 | 랜덤 빵 1개 | 담당자가 지어주는 커스텀 칭호 |

- 오트밀은 관리자 **재고관리 → 이벤트 물품 → 수정**에서 수량을 입력합니다. 판매 메뉴에는 추가하지 않습니다.
- 우유(112)와 두유(113)는 각각 현판·예판 재고를 관리합니다. 판매 가격은 둘 다 1,000원이며 구매 주사위와 랜덤 빵 추첨에서 제외합니다.
- 랜덤 빵은 남은 현판 빵의 `재고² / 전체 재고² 합`으로 추첨합니다. 음료·예판 재고·주문/이벤트 접수로 확보한 수량은 추첨에서 제외합니다.
- 빵·오트밀이 품절이면 보상 신청 전체를 취소하여 자격을 보존합니다. 음료 선택은 품절이면 거부하고 선택권을 유지합니다. 음료 받지 않기는 요청을 종료하며 재추첨하지 않습니다.
- 물품은 지급 대기 요청을 확인하고 전달한 뒤 승인합니다. 재고 확보·지급 대기·승인/취소는 별도 상태로 기록합니다. 물품 취소가 자동 지급된 캐릭터 레벨을 되돌리지는 않습니다. 선글라스는 **계정 관리 → 꾸미기**에서 착용합니다.

## 기존 DB와 배포

- 기존 계정·점수·주문·예약·재고와 과거 주사위/빵 당첨 기록은 유지합니다.
- 최초 실행 때 남은 기존 주사위 수량을 현장 구매 주사위로 한 번만 옮깁니다. 과거 보상은 ‘이전 이벤트’ 기록으로 보존하며 새 5단계 보상과 구분합니다.
- 새 보유량·굴림·보상·오트밀 재고는 추가 테이블에 저장합니다. 운영 초기 재고는 기본 0, 로컬 데모 오트밀 재고는 40개입니다.
- 이번 작업은 로컬 가안입니다. 커밋·푸시·운영 배포는 별도 요청 시 진행합니다.

## 전화번호 계정 전환

가입은 닉네임·전화번호·숫자 4자리 PIN, 로그인은 전화번호·PIN입니다. 번호는 010-NNNN-NNNN 형식으로 저장하며 숫자 11자리 입력도 자동 정규화합니다. 닉네임은 중복 가능하므로 담당자 계정 선택에서는 전화번호를 함께 확인합니다. 사용자 프로필에는 전화번호를 표시/수정하지 않습니다. 기존 DB는 백업 후 재생성하므로 계정·재고·예판은 다시 준비합니다. 구체적인 명령은 README의 기존 clone 재설정 절차를 따릅니다.

## 비회원 구매

- 로그인·가입 화면의 **계정 없이 빵만 구매**에서 이름과 품목을 선택합니다. 주문에 잡힌 재고를 확보하고 담당자가 입금·전달 확인 후 승인하거나 취소합니다.
- 수기판매 → 현장 구매 → **계정 없이 판매**는 이름과 품목만 입력하고 즉시 판매 완료합니다. 예약 수령도 **계정 없이 수령**을 선택할 수 있습니다.
- 계정은 생성하지 않으며 주문 번호는 기존 주문과 같은 자동 증가 정수입니다. 비회원 판매는 매출·판매량에 포함하고 주사위·프로필 보상은 지급하지 않습니다.
- 기존 DB는 삭제하지 않고 자동으로 구조만 업데이트합니다.

## 임의 지급

- **이벤트 → 임의 지급**. 기본은 등록 사용자 선택이며 비회원은 **계정 없이 지급**에서 이름만 입력합니다.
- 빵·상품·점수 중 하나를 선택하고 지급 수량/점수와 사유를 입력합니다. 물품 전달 후 등록하며 즉시 완료로 기록합니다.
- 빵·우유·두유·오트밀은 재고가 차감됩니다. 기타 상품은 상품명·수량만 기록합니다. 프로필 선글라스는 등록 계정에 착용 권한을 부여합니다.
- 비회원은 빵·실물 상품만 가능하고 점수·프로필 소품은 지급할 수 없습니다. 임의 지급으로 구매 주사위나 매출이 추가되지 않습니다.
- 번호·받는 사람·지급 내용·사유·담당자·시각은 같은 화면의 지급 기록에 남습니다. 이미 지급 대기에 있는 물품은 원래 요청에서 승인하거나 취소한 뒤 사용합니다.
