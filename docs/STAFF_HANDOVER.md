# 담당자 인수인계 · 주사위/보상 가안

2026-11-07 로컬 구현 기준. 이 문서는 구매자 화면에 제공하지 않습니다.

## 주사위 지급

| 구분 | 지급 기준 | 구매자에게 보이는 이름 | 6면 구성 (각 면 1/6) |
| --- | --- | --- | --- |
| 예판 일반 | 예약 총액 5,000원 이하 | 준비된 마법사의 주사위 · 일반 | 1, 2, 3, 4, 5, 6 |
| 예판 무지개 | 5,000원 초과~10,000원 이하 | 준비된 마법사의 주사위 · 무지개 | 2, 2, 3, 5, 6, 12 |
| 예판 은색 | 10,000원 초과~20,000원 이하 | 준비된 마법사의 주사위 · 은색 | 3, 5, 7, 9, 11, 18 |
| 예판 금색 | 20,000원 초과 | 준비된 마법사의 주사위 · 금색 | 우유, 6, 9, 11, 15, 22 |
| 현판·수기 현장 판매 | 승인된 빵 1개당 1개 | 현장 구매 주사위 | 1, 2, 3, 3, 4, 5 |
| 인스타 인증 | 계정당 1회, 전용 주사위 1개 | 인싸 마법사의 주사위 | 1, 1, 2, 2, 3, 우유 |

- 예판은 **예약 1건당 해당 등급 1개**. 예약 당시 가격·수량의 합계로 등급을 정하며 우유를 포함한 총액을 사용합니다. 우유만 있는 예약은 구매 주사위를 주지 않습니다.
- 현판 우유는 구매 주사위 제외. 도넛 5개 세트는 빵 1단위입니다.
- 주사위 종류·색·보유 개수만 구매자에게 표시합니다. 면 구성·확률·금액 경계는 공개 화면/API 메타데이터에 넣지 않습니다.
- 결과는 서버에서 추첨합니다. 우유 면은 **0점 + 우유 1개**, 다른 면은 해당 점수를 더합니다.
- 우유 면은 우유의 현판 재고를 차감하고 구매자·담당자 보상 기록에 남습니다. 품절이면 해당 굴리기 전체를 취소하여 주사위·점수를 보존합니다. 재입고 후 다시 시도합니다.
- 인스타 인증 시 우유를 직접 지급하는 기능과 선택 체크박스는 제거했습니다. 예전 인증 이력은 보존합니다.

## 점수 보상

누적 점수로 아래 순서대로 **각 1회** 수령합니다. 한 번에 여러 기준을 넘으면 보상 받기를 순서대로 누릅니다. 30점 이후 점수·순위는 계속 누적하지만 추가 점수 보상은 없습니다.

| 점수 | 현재 구현 | 추후 구현 (화면에 예고만 표시) |
| --- | --- | --- |
| 5 | 오트밀 미니바이트 1개 | 프로필 배지 1 |
| 10 | 우유 1개 | 프로필 배지 2 |
| 15 | 멋진 선글라스 착용 해제 | 칭호 「멋쟁이 마법사」 |
| 20 | 랜덤 빵 1개 | — |
| 30 | 랜덤 빵 1개 | 담당자가 지어주는 커스텀 칭호 |

- 오트밀은 관리자 **재고 → 이벤트 물품 → 수정**에서 수량을 입력합니다. 판매 메뉴에는 추가하지 않습니다.
- 우유는 기존 우유 품목(112번) 현판 재고를 함께 사용합니다.
- 랜덤 빵은 남은 현판 빵의 `재고² / 전체 재고² 합`으로 추첨합니다. 우유·예판 재고·주문 접수로 확보한 수량은 추첨에서 제외합니다.
- 물품 재고가 없으면 해당 보상·레벨은 소비하지 않습니다. 재입고 후 재시도합니다.
- 물품은 보상 화면/기록을 확인하고 현장에서 전달합니다. 기록 생성 시 재고가 이미 차감되므로 재고를 다시 빼지 않습니다. 선글라스는 **계정 관리 → 꾸미기**에서 착용합니다.

## 기존 DB와 배포

- 기존 계정·점수·주문·예약·재고와 과거 주사위/빵 당첨 기록은 유지합니다.
- 최초 실행 때 남은 기존 주사위 수량을 현장 구매 주사위로 한 번만 옮깁니다. 과거 보상은 ‘이전 이벤트’ 기록으로 보존하며 새 5단계 보상과 구분합니다.
- 새 보유량·굴림·보상·오트밀 재고는 추가 테이블에 저장합니다. 운영 초기 재고는 기본 0, 로컬 데모 오트밀 재고는 40개입니다.
- 이번 작업은 로컬 가안입니다. 커밋·푸시·운영 배포는 별도 요청 시 진행합니다.
