# 연금술 메뉴

구매 화면은 실제 메뉴명을 주제목으로 표시하고, 컨셉명은 아래에 회색 보조 글씨로만 표시합니다. 재고 숫자는 숨기며 품절 항목만 회색 처리해 선택을 막습니다. 맛별 상품은 주문·재고·금액을 각각 구분합니다.

| 컨셉명 | 실제 메뉴 | 가격 | 구매·재고 단위 |
| --- | --- | ---: | --- |
| 바람의 정수 | 플레인 휘낭시에 | 2,800원 | 1개 |
| 흙의 정수 | 초코 휘낭시에 | 3,000원 | 1개 |
| 불의 정수 | 카라멜 휘낭시에 | 3,000원 | 1개 |
| 물의 정수 | 무화과 휘낭시에 | 3,400원 | 1개 |
| 고대 마법서 | 로투스 브라우니 치즈케이크 | 3,800원 | 1개 |
| 빛의 결실 | 레몬 다쿠아즈 | 3,500원 | 1개 |
| 현자의 돌 | 얼그레이 다쿠아즈 | 3,500원 | 1개 |
| 구슬 | 글레이즈드 도넛 5개 세트 | 2,000원 | 1세트(5개) |
| 신성한 나무의 열매 | 보늬밤 마들렌 | 2,800원 | 1개 |
| 황금이 들어있는 용광로 | 에그타르트 | 2,800원 | 1개 |
| 황금이 들어있는 용광로 | 치즈타르트 | 2,800원 | 1개 |

휘낭시에 원소 배정과 타르트 구분은 확인한 가안입니다. **도넛 5개 세트는 재고 1단위이며, 승인 시 주사위 1개를 지급합니다.** 이벤트에서 도넛이 당첨될 때도 한 세트를 지급합니다. 주문 내역에는 맛을 구분할 수 있는 실제 메뉴명을 저장합니다.

상품 원본은 `server/catalog.py`입니다. 기존 시연 상품과 다른 번호(101~111)를 사용하여 이전 주문·예판·재고 이력을 보존합니다. 판매 목록과 신규 주문·보상 추첨에는 현재 메뉴만 사용합니다. 기존 예약 수령과 기존 대기 주문 승인·취소는 계속 처리할 수 있습니다.

새 가안은 품목별 현판·이벤트 공용 20단위의 **시연 재고**로 시작합니다. 실제 입고 수량이 아닙니다. 운영용 새 DB는 모든 재고가 0으로 시작하며, 확정된 수량을 담당자가 입력합니다. API 재시작과 메뉴 갱신은 기존 재고를 다시 채우지 않습니다. 이전 버전의 별도 이벤트 재고는 한 번만 현판 재고에 합쳐 총수량을 보존합니다. 추첨 가중치는 남은 현판 재고의 제곱입니다.
