# 디자인·기획 후속 작업

## 이번 가안의 기준

구매자는 모바일에서 재고 확인 → 주문 → 담당자 확인 대기 → 주사위 획득 → 점수와 보상 확인을 진행합니다. 담당자는 노트북에서 대기 건을 빠르게 확인하고 승인·취소합니다. 구매와 이벤트의 진행 상태가 버튼을 누른 뒤에도 분명하게 남아야 합니다.

행사 운영 문구에서 정해야 할 항목은 행사명·캐릭터 이름, 계좌 안내, 예판 수령 안내, 점수 목표, 운영 시간, 상품과 알레르기 안내입니다. 현재 문구와 이미지는 교체 가능한 가안입니다.

## 디자인팀에 전달할 주사위 요청

- 상태: 굴리기 전 / 굴리는 중 / 1~6 결과 / 주사위 없음 / 다음 보상 달성 / 보상 소진.
- 결과: 서버가 확정한 숫자를 애니메이션에 입력합니다. 재시도 시 같은 결과를 다시 보여 주며 클라이언트에서 점수를 새로 뽑지 않습니다.
- 산출물: 모바일 화면 기준 시안, 주사위 면 6종, 결과별 효과, 배경·캐릭터, 파일 형식·용량, 반복·종료 시점.
- 접근성: 결과 숫자와 획득 점수는 텍스트로도 표시합니다. 동작 줄이기 설정을 지원하고 애니메이션 중 여러 번 눌러도 결과는 한 번 반영합니다.
- 승인 대기: 담당자 확인 전에는 주사위를 사용할 수 없다는 상태를 보여 줍니다.

디자인 전달 시 모바일 기본 폭, 색상·타이포, 터치 영역, 로딩·오류·빈 재고 상태를 함께 검토합니다. 담당 화면은 대기 주문의 이름·빵·수량·총액·승인과 취소가 한눈에 보여야 합니다.

## 인스타 캡처용 화면

닉네임, 캐릭터, 점수, 순위, 얻은 빵을 한 장에 담는 카드가 후보입니다. 전화번호·주문 내역 등 개인정보는 공유 카드에서 제외합니다. 인스타 이벤트는 현재 담당자가 사용자별 한 번 지급하며 우유 재고와 주사위 기록을 함께 남깁니다.

## 후속 아이디어

| 아이디어 | 결정할 운영 규칙 |
| --- | --- |
| 휘낭시에 4종 모으기 | 인정 주문, 취소 시 처리, 보너스, 재참여 가능 여부 |
| 퀘스트 | 구매 필수 여부, 중복 수행 기준, 보상 예산·재고 |
| 캐릭터 꾸미기·레벨 | 점수 구간, 교환 비용, 이미지 제작 범위 |
| 후기 | 작성 자격, 수정·삭제, 공개 여부와 운영자 관리 |
| 점수·주사위 이름 | 기획팀 명명, 카드·상태·버튼 문구 통일 |
| 랭킹 | 동점 처리, 실명 노출 대신 별명 사용 여부 |
| 주문 자동 만료 | 입금 대기 시간, 담당자 예외, 재고 반환 시각 |
| 담당 시간표 편집 | 교대 수정 권한, 변경 이력과 알림 |

이 항목들은 다음 단계 제안이며 이번 서버의 기본 구매·승인 흐름에 모두 구현되어 있지는 않습니다.
