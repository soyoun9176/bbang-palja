# 화면 구성과 구현 범위

이번 가안은 요청된 구매·이벤트·담당자 기능과 캐릭터 프로필 꾸미기를 제공합니다. 후기, 퀘스트, 빵 조합, 공유 카드 등 추가 아이디어는 구현 범위에서 제외합니다.

## 구매자 · 모바일

첫 화면은 전화번호와 숫자 4자리 비밀번호 입력입니다. 가입 시 이름(닉네임)·전화번호·비밀번호를 받습니다. 전화번호는 숫자 11자리 또는 010-NNNN-NNNN만 허용하며 자동으로 대시를 넣습니다. 중복 전화번호는 거부하고 닉네임 중복은 허용합니다. 계정 전화번호 변경 기능은 두지 않습니다. 예약 조회 화면에는 본인 닉네임·전화번호를 기본 표시하고 조회 입력값만 수정할 수 있습니다. 로그인 이후 상위 메뉴는 **빵 구매 / 이벤트 참여** 두 개뿐입니다.

### 캐릭터 프로필

- 아직 꾸미기를 저장하지 않은 계정은 로그인 직후 연금술사 꾸미기를 엽니다. **다음에 꾸미기**로 건너뛸 수 있으며, 상단 내 프로필을 눌러 **계정 관리**에서 언제든 변경합니다.
- 탭은 **얼굴 / 표정 / 꾸미기**입니다. 얼굴은 마들렌·휘낭시에·파운드케이크와 굽기 정도, 표정은 방긋·활짝·윙크·깜짝 중에서 고릅니다. 마들렌의 조개 무늬·휘낭시에의 노릇한 직사각형·파운드케이크의 도톰한 단면에 눈·코·입을 그립니다.
- 꾸미기에서 안경과 구매한 빵 머리핀을 함께 착용하거나 해제합니다. 빵 머리핀은 현재 메뉴 11종에 각각 대응하며, 현장 구매·예약 수령·수기 판매의 **승인된 주문**에 해당 상품이 있어야 선택할 수 있습니다. 승인 대기·취소 주문, 우유, 랜덤 빵 당첨이나 인스타 인증은 머리핀을 열지 않습니다. 같은 빵을 여러 번 사도 한 종류만 열립니다. 다른 사람의 구매 내역은 노출하지 않습니다.
- 열린 머리핀을 먼저 표시하고 잠긴 머리핀은 접어서 보여줍니다. 서버도 소유 여부를 확인합니다. 꾸미는 중에 구매가 승인되면 선택한 표정을 유지한 채 머리핀 목록을 갱신합니다. **멋진 선글라스**는 15점 보상을 받은 계정에서만 선택합니다. 프론트에서 잠그고 서버도 권한을 검사합니다.
- 선택 즉시 미리보기를 바꾸고 **이 모습으로 저장**을 눌러 계정에 저장합니다. 저장하지 않고 닫으면 기존 프로필을 유지합니다. 이전 머리 모양·색은 새 구성에서 사용하지 않으며, 이전 프로필에는 기본 표정과 미착용 머리핀을 적용합니다.
- 꾸민 캐릭터를 프로필 사진으로 사용합니다. 모든 순위 항목·내 계정·담당자 주문 카드와 구매자 선택·이벤트 기록에 표시하며, 미설정 계정에도 일관된 기본 프로필을 제공합니다. 실제 사진 업로드는 없습니다.
- 저장한 외모는 다시 로그인해도 유지되고 다른 사람의 순위 화면에도 반영됩니다. 저장 실패 시 선택 내용과 오류 안내를 유지합니다. 프로필 변경은 점수·주사위·재고·레벨을 바꾸지 않습니다.
- 성장 캐릭터의 미획득 자리는 계속 물음표입니다. 획득한 단계는 같은 외모에 레벨별 연금술사 의상·장식을 입혀 표시합니다.

### 빵 구매

- 현판 구매: 실제 메뉴명·가격·수량 선택 → 선택한 빵과 합계 → 구매 요청 → 담당자 승인 대기.
- 실제 메뉴명을 주제목으로, 컨셉명은 아래에 작은 회색 글씨로 표시합니다. 구매 목록에는 재고 숫자나 컨셉 아이콘을 표시하지 않습니다. 왼쪽에는 메뉴별 양피지풍 빵 일러스트를 표시합니다. 실물 사진이 준비되면 경로를 교체할 수 있고, 이미지가 없거나 로딩에 실패하면 중립적인 빈 영역을 표시합니다. 품절 항목만 회색 처리하고 수량 버튼을 비활성화합니다.
- 예판 수령: 가입 닉네임·전화번호 기본 입력 → 필요하면 이름·전화번호를 수정해 조회 → 예약 빵 확인 → 수령 요청 → 담당자 승인 대기. 조회값은 계정 정보에 저장하지 않으며 다른 계정에 이미 접수된 예약은 가져오지 않습니다.
- 주문 내역: 대기·수령 완료·취소 상태와 금액을 표시합니다. 승인된 주문에서 이벤트 화면으로 이동할 수 있습니다.
- 우유·두유는 각각 1,000원으로 함께 판매하며 ‘주사위 미지급’을 표시합니다. 주문 금액·수량에는 포함하지만 구매 주사위는 빵 수량만 계산합니다.
- 구매 화면에는 점수 카드, 주사위, 순위, 뽑기 화면을 표시하지 않습니다.

### 이벤트 참여

- 이벤트는 **점수·주사위·순위를 한 페이지**에 표시합니다. 별도 주사위 탭은 없으며 기존 `#dice` 주소도 `#ranking`으로 연결합니다. 양일 누적 상위 3명과 본인 위·아래 최대 두 명을 표시하며 날짜가 바뀌어도 자동 초기화하지 않습니다.
- 개인 카드에 현재 점수·다음 보상·종류별 주사위 선택을 모읍니다. 선택한 주사위를 같은 페이지에서 굴리고, 주사위가 없으면 **빵 구매하고 주사위 얻기** 버튼을 표시합니다.
- 현판은 빵 1단위당 1개, 예판은 예약 금액 등급의 **준비된 마법사의 주사위** 1개, 인스타 인증은 **인싸 마법사의 주사위** 1개입니다. 색·이름·수량만 표시하고 면 구성·확률·금액 경계는 사용자 화면/API 메타데이터에 넣지 않습니다.
- 결과는 서버에서 추첨합니다. 숫자는 점수, 우유 면은 우유·두유 중 하나를 고르는 선택권입니다. 굴리는 동안 중복 동작을 막고 완료 후 결과와 보상 기록을 갱신합니다.
- 보상 로드맵: **5점 오트밀 미니바이트 / 10점 우유 또는 두유 / 15점 멋진 선글라스 / 20점 랜덤 빵 / 30점 랜덤 빵**. 5점·10점 보상에는 프로필 배지를 함께 지급합니다. 15점은 멋쟁이 마법사, 30점은 대현자 연금술사 칭호를 지급하며 담당자가 커스텀 칭호를 추가·지급할 수 있습니다.
- **N점 더 모으면 레벨업!**과 다음 물품을 표시합니다. 각 기준에서 보상 받기를 한 번씩 누르며, 30점 이후에는 순위 경쟁만 이어집니다. 보상 성공 시 캐릭터가 Lv.1~5로 성장합니다. 첫 캐릭터 획득 전에는 물음표를 표시합니다.
- 넓은 화면은 개인 카드 옆에 순위, 모바일은 아래에 순위를 표시합니다. 받은 보상은 접어서 표시합니다. 물품 요청·지급 대기·수령 완료/취소 상태를 보여줍니다. 음료 선택 요청은 개인 카드 위에 표시하여 닫았다가도 다시 선택할 수 있습니다. 품절 품목은 비활성화하고 둘 다 품절이면 받지 않기를 제공합니다.
- 빵 보상은 남은 현판 재고의 제곱에 비례해 추첨합니다. 우유·예판·접수 확보 수량은 제외하며 확률 설명은 구매자 화면에 표시하지 않습니다. 빵·오트밀 부족은 보상 신청을 롤백합니다. 음료는 선택할 때 재고를 확인하며 부족하면 다른 품목 선택·미수령이 가능합니다. 이미 나온 주사위 결과를 재추첨하지 않습니다.

## 담당자 · 노트북

상단에 **주문 / 이벤트 / 수기판매 / 재고관리 / 인수인계** 다섯 메뉴만 표시합니다. 전체 재고는 재고 화면에서 확인하고, 주문별 품목 옆에는 현재 남은 재고를 괄호로 표시합니다. 예판 주문은 별도 예판 재고를 표시합니다. 각 화면의 기능 설명은 접어서 표시합니다.

| 화면 | 기능 |
| --- | --- |
| 주문 | 예판·현판 이름, 빵·수량, 합계, 승인·취소. 이름·예약 전화번호·메뉴 검색과 주문 상태 필터. 새 주문은 자동 표시 |
| 수기판매 | 현장 구매 / 예약한 빵 수령 선택. 현장은 구매자·수량·합계 입력 후 판매 완료, 예약은 이름·전화번호 일부·메뉴 검색 → 예약 확인 → 수령 계정 선택·승인 |
| 재고관리 | 빵·우유를 같은 표에서 관리. 오트밀은 이벤트 물품 카드에서 관리. 현판·이벤트 공용 / 예판 / 접수 보관 수량, 수량 증감과 사유, 변경 이력, 예판 예약 등록, 버튼으로 펼치는 예판 수령 현황 |
| 이벤트 | 물품 지급 대기·음료 선택 중·지급 완료·취소, 검색, 승인/취소. 인스타 인증은 내부 탭에서 처리 |
| 인수인계 | 전임자 메모, 메모 작성, 담당자 시간표 |

예판 예약 등록은 이름·전화번호·빵 수량을 입력하는 폼입니다. 운영 화면에 JSON이나 빵 ID 입력을 요구하지 않습니다. 별도의 통계 홈, 홍보 배너, 독립 이용 가이드 메뉴는 두지 않습니다.

수기 판매의 **예약한 빵 수령**에서는 예약 당시 품목·수량·금액을 그대로 보여주며, 수량을 새로 입력하지 않습니다. 미접수 예약은 **기존 계정에 추가 / 새 계정 만들기**를 선택합니다. 기존 계정은 담당자가 구매자 목록에서 선택하며 예약자 이름과 계정 이름이 달라도 연결할 수 있습니다. 주사위와 주문 내역은 선택한 계정에 추가되고 원래 예약자 정보는 유지합니다. 새 계정은 예약자 이름과 숫자 4자리 비밀번호로 만들고 담당자가 비밀번호를 구매자에게 알려줍니다. 이미 접수된 수령 요청은 연결된 계정과 같은 주문으로 승인합니다. 완료한 예약은 수령 계정과 완료 내역만 표시하고 재승인 버튼은 숨깁니다.

관리자 검색은 예판 현황·예약 수령·주문 확인에만 표시합니다. 이름·전화번호 일부(끝자리 포함)·메뉴로 검색하며, 전화번호의 하이픈·공백은 무시합니다. 여러 단어를 입력하면 모두 포함된 항목만 표시합니다. 수령 화면은 검색 결과의 **예약 확인** 버튼을 눌러 서버의 최신 내역과 수령 상태를 가져온 뒤 승인합니다. 다른 예약을 검색하면 이전 선택과 진행 중인 조회 결과를 초기화합니다. 기존 계정은 이름으로 검색해 목록을 좁힐 수 있으며, 계정 검색어를 변경하면 이전 계정 선택을 해제하므로 수령 계정을 다시 선택해야 합니다. 검색어와 펼친 현황은 자동 갱신 후에도 유지하고 입력 중에는 포커스를 바꾸지 않습니다. 사용자 예약 조회는 가입 번호를 서버에서 확인하며 화면에서 번호를 다시 입력하지 않습니다.

재고의 **예판 수령 현황** 버튼은 처음에는 접혀 있습니다. 펼치면 검색창과 이름·전화번호·메뉴·수령 상태 표를 보여줍니다. 메뉴는 ‘플레인 휘낭시에 2개, 초코 휘낭시에 1개’처럼 한 셀의 줄글로 표시하고, 상태는 수령 대기 / 수령 요청 접수 / 수령 완료로 구분합니다. 검색 결과가 없으면 안내를 표시하고 검색어를 지우면 전체 목록으로 돌아갑니다. 승인·취소 결과를 자동 갱신하며 표를 펼친 상태는 유지합니다.

## 디자인팀 주사위 애니메이션 요청

현재는 임시 CSS 애니메이션입니다. 필요한 상태는 굴리기 전 / 굴리는 중 / 1~6 결과 / 주사위 없음 / 목표 달성 / 보상 소진입니다. 서버가 확정한 숫자를 표현하고 결과 숫자·점수는 텍스트로도 보여줍니다. 모바일 시안과 주사위 면 6종, 시작·종료 시점, 파일 형식·용량을 정하면 교체합니다. 동작 줄이기 설정에서는 애니메이션을 생략합니다.

## 저장소와 실행 환경

Cloudflare Pages와 Oracle Quick Tunnel 구성은 유지합니다. DB 쓰기 잠금과 재고·승인 중복 방지는 기존 API에서 처리합니다. PostgreSQL 어댑터도 공통 쓰기 잠금을 지원합니다. 현재 공개 가안은 별도 SQLite 샘플 DB를 사용하며, 이번 화면 정리에서 DB 엔진 전환이나 샘플 데이터 초기화는 하지 않습니다.

이벤트 물품은 요청 시 확보하고 담당자 승인은 차감을 유지, 취소는 확보한 1개만 반환합니다. 선글라스 등 디지털 보상은 자동 지급하며 취소·재추첨 대상이 아닙니다. 과거 지급 기록은 새 대기 목록에 소급하지 않습니다.

레벨업 보상은 0~30점 누적 막대로 표시합니다. 5·10·15·20·30점 위치의 작은 말풍선 안에 상품 일러스트를 넣고 미달성은 회색, 달성은 컬러로 표시합니다. 말풍선을 누르면 상품명·배지/칭호·달성 상태를 보여줍니다. 달성·미수령 보상에만 **상품 받기** 버튼을 표시하고, 선택한 단계의 보상만 신청합니다. 이미 신청한 단계는 체크로 표시하고 물품 지급/취소 상태를 안내합니다. 남은 단계와 무관하게 달성한 보상을 각각 받을 수 있습니다. 상품 일러스트는 `assets/oatmeal.svg`, `milk.svg`, `sunglasses.svg`, `reward-bread.svg`입니다.


## 프로필 배지 (로컬 작업)

계정 관리 → **배지**에서 보유 배지 하나를 선택해 저장하거나 해제합니다. 착용 배지는 프로필 사진 왼쪽 위에 겹쳐 표시하며, 순위·내 프로필·담당자 목록에서도 같은 모습입니다. 미획득 슬롯은 회색 물음표이고 누르면 배지 이름과 획득 안내가 나옵니다.

5점 보상은 **마법의 씨앗**, 10점 보상은 **빛나는 연금술** 배지를 함께 지급합니다. 다른 조건의 배지는 관리자 **이벤트 → 임의 지급 → 배지 → 배지 추가·보유 현황**에서 이름·획득 안내·그림을 등록하고 조건 확인 후 지급합니다. 배지 지급은 착용을 자동 변경하지 않습니다.


## 칭호·도전과제 (로컬 작업)

- 이벤트의 **내 주변 순위**를 **도전과제**로 교체합니다. TOP 3와 본인 순위 숫자는 유지합니다.
- 도전과제 카드는 진행도·달성 상태를 표시하며 누르면 조건, 품목별 구매량, 배지·칭호 보상을 보여줍니다. 승인 후 자동 지급하며 별도 받기 버튼은 없습니다.
- 휘낭시에 4종: **원소 수집가** / 빵 11종: **캄딜 VVIP** / 같은 빵 5개: **메뉴명 몰입가**. 우유·두유와 무료 지급은 제외하며 승인된 예판·현판·수기 구매를 합산합니다.
- 신청 순서대로 등록한 예판 첫 10명과 한국 시간 날짜별 현장 첫 주문자는 **⚡ 우사인볼트 연금술사**를 얻습니다. 예판 수령·현장 구매가 승인되어야 합니다.
- 계정 관리 → **칭호**에서 보유한 것 하나를 선택·해제합니다. 이름 옆에 반짝이는 작은 칭호를 표시하며 VVIP는 금색, 선착순은 번개 스타일입니다. 첫 칭호와 VVIP는 자동 착용하고 이후 프로필에서 바꿀 수 있습니다. 움직임 줄이기 설정을 존중합니다.
- 도전과제 배지 4종: [이미지·생성 프롬프트](BADGE_ASSETS.md). 미획득 배지는 프로필 탭에서 물음표를 유지합니다.


## 메뉴 이미지·수기판매 배치 (로컬 작업)

- 빵 11종을 같은 양피지·세밀화 톤의 개별 일러스트로 제공합니다. 구매자 메뉴와 담당자 현장 수기판매·예약 수령 내역이 같은 이미지를 사용합니다. [파일·생성 프롬프트](PRODUCT_ART.md)
- 수기판매 현장 메뉴는 컴퓨터에서 3열 카드입니다. 작은 화면에서는 2열, 휴대폰에서는 1열로 줄이며 카드에 이미지·실제 메뉴명·가격·재고·수량 입력을 모읍니다.
- 기존 사용자 선택·비회원/신규 처리·금액 계산·품절 비활성화·판매 승인 흐름을 유지합니다. 구매자 메뉴에는 재고 숫자를 표시하지 않습니다.
